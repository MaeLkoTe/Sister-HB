# Семейный банк

Мобильное поздравление для сестры в формате SPA. Приложение сделано на HTML, CSS и JavaScript без сборки и сторонних зависимостей, поэтому его можно сразу разместить на любом статическом хостинге.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```sh
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Настройка поздравления

Все тексты, подписи сторис, операции, комплименты и пути к фотографиям находятся в [data.js](data.js). Укажите `avatarImage` и `media.src` для историй относительно корня сайта, например `images/sister.jpg`. Для видео у нужной истории задайте `media.type: "video"`.

## Telegram-приглашение

Бот по `/start` или `/help` присылает поздравление с кнопкой перехода в «Семейный банк». Он отвечает только в личных сообщениях. Код: [bot/bot.cjs](bot/bot.cjs), настройки: [bot/config.example.json](bot/config.example.json).

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, задайте имя «Семейный банк» и уникальный username, заканчивающийся на `bot`. Сохраните выданный токен.
2. Установите Node.js 22 или новее. Дополнительные пакеты не нужны.
3. Из корня проекта в PowerShell создайте свой конфиг:

   ```powershell
   Copy-Item bot/config.example.json bot/config.local.json
   ```

4. Откройте `bot/config.local.json` и вставьте токен между кавычками в поле `token`. Там же можно изменить `message`, `buttonText` и `siteUrl`. Локальный файл исключён из Git; не переносите токен в пример конфига или файлы сайта. Вместо записи токена в файл можно использовать переменную окружения `TELEGRAM_BOT_TOKEN`.
5. Запустите:

   ```powershell
   node bot/bot.cjs
   ```

6. Откройте ссылку `https://t.me/USERNAME_БОТА`, нажмите **Старт** и проверьте поздравление и кнопку. Эту же ссылку отправьте сестре с подписью «Тебе письмо 💌».

Бот работает, пока запущен процесс и компьютер подключён к интернету. GitHub Pages размещает только сайт и не запускает бота. Для постоянной работы запустите ту же команду на сервере с Node.js 22+. Остановка — `Ctrl+C`. Запускайте только одну копию с одним токеном. Бот сохраняет обработанный номер обновления в локальном `bot/.state-*.json`, чтобы при перезапуске не повторять обработанные приглашения. Повторный `/start` намеренно снова показывает поздравление.

Токен пока не задан: реальная отправка проверяется после вашего запуска. Документация используемых методов: [Telegram Bot API](https://core.telegram.org/bots/api#getupdates).
