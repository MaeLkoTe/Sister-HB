# Семейный банк

Мобильное поздравление для сестры в формате SPA. Приложение сделано на HTML, CSS и JavaScript без сборки и сторонних зависимостей, поэтому его можно сразу разместить на любом статическом хостинге.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```sh
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Настройка поздравления

Все тексты, подписи сторис, операции, комплименты и пути к фотографиям находятся в [data.js](data.js). Укажите `avatarImage` и `media.src` для историй относительно корня сайта, например `images/sister.jpg`. Для видео у нужной истории задайте `media.type: "video"`.
